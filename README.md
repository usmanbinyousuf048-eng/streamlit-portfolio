# 📊 Streamlit Data Analysis Portfolio

A collection of interactive data analysis applications built with **Python**, **Pandas**, and **Streamlit**.

---

## 🚀 Live Projects

### 1.Data Analyzer
https://general-data-analyzer.streamlit.app/

**Upload a CSV file → Explore, filter, visualize, and export your data**

* Upload and analyze CSV datasets
* Automatic data preview and statistical summaries
* Dynamic filtering by column and value
* Interactive plotting with selectable X and Y axes
* Missing value detection and one-click removal of rows with missing values
* Export filtered data as a CSV file
* Tested with 5+ diverse datasets

**Tech:** Python · Pandas · Streamlit

### 2. Job Market Intelligence Dashboard
https://job-market-data-analyzer.streamlit.app/

**Explore technology job market trends, salaries, and demand**
